# 🌡️⚖️📏 Unit Converter Web App

## 🧩 Overview
A simple and responsive **Unit Converter** built with **HTML, CSS, and JavaScript**.  
It allows users to convert between common units of:

- 🌡️ Temperature (farenheit = (celsius * 9/5) + 32)  
- ⚖️ Weight (Kilogram = pounds * 2.2)  
- 📏 Distance (Miles = km * 0.62137)


## 🛠️ Technologies
- **HTML5** for structure  
- **CSS3** for design and responsiveness  
- **JavaScript** for conversion logic  

## 🚀 How to Run
1. Download or clone the project.  
2. Open `index.html` in your browser.  
3. Start converting units instantly!
